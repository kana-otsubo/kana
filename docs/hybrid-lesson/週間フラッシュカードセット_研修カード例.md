# 週間フラッシュカードセットの実例（研修カード①）

出典：`週間フラッシュカードセット_研修カード例.pdf`（可奈さん提供の実物写真）

> これは **1週間分（＝1回のレッスン分）のフラッシュカードの中身** の実物。
> **毎週、下の「決まった枠（分類）」に、その週のカードを選んで入れる** ── これが「フラッシュカードの入れ方」の具体形。
> ベンダーの言葉でいう **「フラッシュカードレッスン（セット）」1件** に相当する。

## 構造の要点

- **行＝分類（枠）は固定**。約19枠。毎週この枠は変わらず、中身（どのカード）だけ差し替える。
- **年齢帯**：一部の枠は **1〜3才 / 4〜6才** に分かれる（基礎概念・もじ・かず・右脳）。
- つまり「週プログラムのフラッシュカード」＝**このテンプレートを1枚埋める**作業。
