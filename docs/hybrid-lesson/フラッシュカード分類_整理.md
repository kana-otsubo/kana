# フラッシュカードの分類と入れ方（整理）

> 可奈さんの困りごと：「フラッシュカードは膨大。毎週プログラムに入れるので、**分類が整理されていないと困る**。**大分類・中分類**という言い方もよく分からない。」
>
> 結論：**あなたの分類（発注表の「分野」）と、ベンダーの分類（サブジャンル）は、実はもう一致しています。** 言葉が違うだけ。下でそろえます。

---

## 1. モヤモヤの正体＝「言葉が2種類ある」

- **あなたの頭の中**：大分類 → 中分類 → 小分類（階層で考えている）
- **ベンダーの設計**：大分類/中分類という言い方はやめて、**「3本の軸＋タグ」**で分類している（議事録「CMSジャンル分類」）

言い方が違うだけで、やりたいことは同じ＝「膨大なカードを、選びやすく整理する」。

---

## 2. ベンダーの分類＝「3本のマスタ軸＋難易度＋タグ」

レッスン教材を、独立した軸の組み合わせで分類・検索する（検索は AND＝掛け合わせ）。

| 軸 | 意味 | 中身 |
|---|---|---|
| **① ジャンル(形式)**（1つだけ）| どう体験するか | 歌／動画／**フラッシュカード**／リンクカード／リトミック／粗大運動／バスゲーム／対話ゲーム／図形タイム／実験／タッチタイム(育脳・復習)／今月の〜 |
| **└ サブジャンル**（ジャンル配下）| フラッシュカードの種類 | 百科事典／基礎概念／もじ(文字カード)／かず(数カード)／右脳／IQ／絵画／ことわざかるた／百人一首／反対語／四字熟語／俳句 |
| **② ねらい** | 何の力を育てるか | **Kulabo 25領域**（言語/健康/認知・行動/人間関係/運動・感覚 の5大領域×各5項目）|
| **③ 年齢** | 対象 | **s01〜s24（月齢3か月刻み）** ／ 全・2・3・4・5・6歳 |
| **④ 難易度** | むずかしさ | 1〜5 |
| **⑤ タグ**（自由・複数OK）| 何でも入る絞り込み | 細分類(あんしょう/反対語/九九…)／題材(動物/数/かたち/もじ/のりもの)／出所(コペルン由来/Kulabo由来/HL自前)／自由(季節/お気に入り) |

**検索イメージ**：ジャンル=フラッシュカード AND サブジャンル=百科事典 AND 年齢=3歳 → 大量から数件に絞る。

👉 つまり：**あなたの「大分類」＝ジャンル（フラッシュカード）／「中分類」＝サブジャンル（百科事典・もじ…）** と対応します。

## 4. プログラムへの入れ方（毎週の運用）

議事録より、フラッシュカードは**プログラムに直接カードを入れるのではなく、「セット」を作って選ぶ**形：

```
プログラム管理
 └ レッスン管理
    └ フラッシュカードレッスン（＝設定済みセット。100件くらい用意）
       └ フラッシュカードセット（1〜n枚。100枚設定も可）
（リンクカードも同様）
※イメージは「月レッスン・週レッスン構築画面」に近い（ドリルダウンで絞って選ぶ）
```

**毎週の作業**：ジャンル=フラッシュカード → サブジャンル（例:百科事典）→ 年齢 で絞って、使うセットを選んで週プログラムに入れる。

### 実物でみる「1週間分のセット」＝固定枠テンプレート
可奈さん提供の実物（研修カード①／`週間フラッシュカードセット_研修カード例.md`）で、毎週の入れ方が具体的に分かった：
- **約19の固定枠**（リンク/百科事典/ことわざ/反対語/四字熟語/俳句/基礎概念/もじ/かず/右脳/IQ/実数/絵画/英単語/English Diary）が毎週決まっていて、**中身のカードだけ差し替える**。
- 一部の枠は **1〜3才／4〜6才** に分かれる。
- → ベンダーの「フラッシュカードレッスン（セット）」＝**この固定枠テンプレートを1枚埋めたもの**。テンプレ保存＆毎週コピーができるか要確認（§5に追記済み）。
