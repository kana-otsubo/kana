# 数 全段 12週プラン（s09〜s28｜2歳〜6歳）

各段（3か月＝約12回）を、**同じねらい・毎週ちがう見せ方**で進める12週スパイラル。
7フェーズ：**導入(1–2)→実物(3–4)→記号(5–6)→基数性/展開(7–8)→応用(9–10)→挑戦(11)→発表(12)**。
詳しい見本は `週プラン_数_s13_12週`（1マスずつ声かけ付き）。ここは全段をコンパクトに。
※s13は下に再掲。0〜1歳（s01–s08）は「数の前」＝`数論理_28段_各行詳細`参照。

## 使い方
- 各段の **7フェーズ = 12週の骨**。細部（声かけ・復習）は `週プラン_数_s13` の形で必要な段だけ肉付け。
- 個人差：早い子は次の段の導入を先取り／ゆっくりの子は前フェーズの復習を厚く。
- 次：この骨に **167ゲーム・カードを各週へ正式に配置** → 数の週プログラムが全段そろう。
