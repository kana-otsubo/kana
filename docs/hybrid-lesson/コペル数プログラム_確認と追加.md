# コペルの数プログラム 確認と「足すべきもの」

出典：`materials/コペル数リトミック図形プログラム_教室版.pdf`（各教室が追加している実物・年齢×月）。
目的：**我々の数28段が、コペルの数プログラムを網羅しているか**を確認し、**足すべきもの**を出す。「レベルが下がった」と言わせない。

## コペルの数プログラムの構成（実物）
5ページ＝①かずのうた・100玉そろばん・数表 ②かずプログラム(教室＋BOX＋そろばん) ③かずBOX(合成分解) ④リトミック ⑤ローテーション(図形・英語・理科社会歴史ソング)。数の中身：

- **かずのうた**：0-20→21-40→…→81-100（**数唱を100まで・月ごと**、1〜2歳から歌で）
- **100玉そろばん（百玉）**：実数ロケット(1〜10階段)／**合成(1と2・2と3…)**／実数読み(2段・3段)／実数とり／数えて／指差／**インプット・アウトプット**
- **5とび・10とびのうた**（skip counting）
- **音の数**（音を聞いて数える・3〜10まで）
- **実数**：実数分け(皿に分ける)・実数プリント・数字マグネット・数字パズル
- **合成分解**：4の合成〜10の合成／**合成分類箱＆歌**／10の合成ルーレット／サイコロたし算
- **たし算・引き算**：あわせていくつ／10-0の引き算／20まで／20-0
- **掛け算**：**掛算1〜3・4〜6・7〜9**（★4歳から・九九の歌的に）
- **マス計算**：番号順に進む（5〜6歳・15番→48番…）
- **そろばん(小)**：段・15/20までの足し算引き算・2桁+2桁・2桁を2つで言わせる
- **お金**：お金プリント・お金の種類・大きな数(積み木)

## ⚠️ 足すべきもの（これを足せばコペルを網羅＝下がらない）
1. **100玉そろばんを「数の毎日の柱」に明示**（実数ロケット/合成/実数読み/実数とり/数えて/指差/インプット・アウトプット）。コペルの数の中核。
2. **掛け算（掛算1〜9）を4〜6歳に追加**（九九のうた的に。★最大の虫食い）。
3. **マス計算**を5〜6歳に追加（番号順プリント）。
4. **5とび・10とびのうた**（skip counting song）を早め（3〜4歳）に。
5. **音の数**（聴覚で数える）を追加。
6. **合成分類箱**（BOX合成分解教具）を手立てに。
7. **数唱は歌で100まで早期に触れる**（コペル流の“先取り露出”）を明示。
8. お金・数字マグネット・実数分け・大きな数 を手立てに追加。

## 反映方針（発達は主・コペルは網羅すべき中身）
- **発達段階の順序は主**のまま、上の**具体メソッド（百玉そろばん・掛け算・マス計算・とび歌・音の数）を各段の「手立て」「到達」に足す**。
- 特に **掛け算・マス計算・百玉そろばん** は「コペルにあって我々に無い/弱い」＝**必ず足す**。
- これで「網羅されているか？」→ **足せば網羅**、と言える。
