# 発達ステージ 12段階 → 24段階 への移行方法

> 目的：これまでの **12段階（6か月刻み）** を、**24段階（3か月刻み）** に変更する。
> 理由：同じ「3歳クラスの4月」でも、2歳1か月〜3歳11か月の子が混在する。6か月刻みでは粗すぎるので、**3か月刻みで階段を細かく**して、一人ひとりに合った難易度を出せるようにする。

## 1. 基本ルール：1段 → 2段に割る（機械的で確実）

現在の各ステージ（月齢6か月幅）を、**前半3か月／後半3か月**の2つに割るだけ。

| 旧（12段階・6か月）| 月齢 | → 新（24段階・3か月）|
|---|---|---|
| S5 | 30〜35か月（2歳6か月〜）| s09（前半）＋ s10（後半）|
| S6 | 36〜41か月（3歳0か月〜）| s11 ＋ s12 |
| S7 | 42〜47か月（3歳6か月〜）| s13 ＋ s14 |
| S8 | 48〜53か月（4歳0か月〜）| s15 ＋ s16 |
| S9 | 54〜59か月（4歳6か月〜）| s17 ＋ s18 |
| S10 | 60〜65か月（5歳0か月〜）| s19 ＋ s20 |
| S11 | 66〜71か月（5歳6か月〜）| s21 ＋ s22 |
| S12 | 72〜83か月（6歳〜）| s23 ＋ s24 |

- **公式**：旧 `S(n)` → 新 `s(2n−1)`（前半3か月）と `s(2n)`（後半3か月）。
- 旧S1〜S4（0〜2歳台）も同様に s01〜s08 に割れる（幼児教室の対象は概ね S5＝s09 以降）。

## 2. 手順（アーキテクチャとして何をするか）

**Step 1｜段の定義を差し替える**
- ステージ表を「12行」から「24行」に。各行に **月齢レンジ（3か月幅）** を持たせる。
- ベンダーの `s01–s24`（3か月間隔）と **月齢の起点をそろえる**（＝ここだけ要確認。上表は旧データの起点に合わせた案）。

**Step 2｜既存コンテンツの段を貼り替える**
- 各ゲーム／カードの「旧S」を、上の表で機械的に「新s（2つ）」へ。
- まずは **範囲（例：S7→s13〜s14）** として持たせ、動きを止めない。

**Step 3｜難易度で前半/後半に振り分け（精緻化）**
- 範囲のままでもよいが、より細かくしたい課題は、その課題の「やさしい→むずかしい」で **前半(s13)／後半(s14)** に割り当てる。
- 例：同じ「数」でも "5まで" は前半、"10の合成" は後半、のように。

**Step 4｜クラス運用に載せる**
- クラス（3・4・5・6歳）の子に、月齢から**現在の s ステージ**を割り当て、その段のコンテンツを出す。

## 3. 167ゲームへの適用（下書き済み）

`ハイブリッド167本_ゲーム一覧.csv / .md` に **「新ステージ(24・下書き)」列**を追加済み。
- 現状は Step 2 まで（範囲＝機械変換）。**Step 3（難易度で前半/後半に確定）は、課題ごとに一緒に決める**。
- 旧S分布：S5:2 / S6:21 / S7:42 / S8:41 / S9:35 / S10:18 / S11:7 / S12:1（=167本）。

## 4. ベンダーに確認・依頼すること

1. **段の起点合わせ**：ベンダーの `s01` が月齢何か月始まりか。上表（旧起点）と一致するか。
2. ステージを **12→24に増やす**こと、各段に**月齢レンジ**を持たせること。
3. 子の**月齢から現ステージを自動算出**し、該当段のコンテンツを出せること。
4. コンテンツは**ステージ範囲（from〜to）**で持てると運用しやすい（例：s13〜s14）。
