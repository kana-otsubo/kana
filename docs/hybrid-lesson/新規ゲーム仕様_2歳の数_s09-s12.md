# 新規ゲーム仕様：2歳の数（s09〜s12）

**課題**：167本で手薄だった **2歳台の数ゲーム**を新規に設計。
**対象**：2歳（s09–s12）／数の要素＝数唱1〜5・計数1対1(1〜3)・subitizing・量の比較・基数性の芽。
**2歳の設計原則**：①1タップだけ（指追従・長押し不要）②対象は大きく(最小64px)③即時ごほうび（音・光）④短い⑤失敗してもエラーにしない。

そろばんゲームは**先生が見せればOK**なので優先度低（§末の宿題へ）。

---

## N-01 「どっちが おおい」｜量の比較
- **段/年齢**：s09–s10（2歳0–5か月）
- **エンジン**：E01 選択型（V1_picture）／renderKind: choice_picture
- **1画面ゴール**：多い方を選ぶ
- **画面の動き**：上に2つのお皿。片方に3個・片方に1個のくだもの。多い方をタッチ→キラキラ。
- **問題文（ひらがな）**：「おおいのは どっち？」
- **操作**：大きい選択肢2つを1タップ
- **見たい力**：量の比較・subitizing
- **ラウンド進行**：3対1 → 3対2 → 2対1（差を少しずつ小さく）
- **素材**：くだもの/どうぶつ（研修カードの百科事典と共通化可）

## N-02 「かぞえて タッチ」｜計数1対1（1〜3）
- **段/年齢**：s09–s11
- **エンジン**：E06 操作型（count）
- **1画面ゴール**：物を1つずつ数える
- **画面の動き**：りんご1〜3個。1つタッチごとに「いち・に・さん」と音声＋印がつく。最後に「できた！」
- **問題文**：「りんごを かぞえてね」
- **操作**：1つずつタップ（順不同OK）
- **見たい力**：計数・1対1対応
- **ラウンド進行**：1個 → 2個 → 3個
- **記録**：数え終えたか／重複タップの有無

## N-03 「ぱっと みて おなじ かず」｜subitizing（1〜3）
- **段/年齢**：s11–s12（2歳6–11か月）
- **エンジン**：E01 選択型（V1_picture）
- **1画面ゴール**：見た数と同じ数を選ぶ
- **画面の動き**：上に ●●（ドッツ）を1〜2秒 → 下の選択肢（●／●●／●●●）から同じ数をタッチ。
- **問題文**：「おなじ かずは どれ？」
- **操作**：1タップ
- **見たい力**：subitizing（数えずに分かる）
- **ラウンド進行**：1 → 2 → 3、提示時間を少し短く
- **メモ**：ドッツは規則配置から。将来ランダム配置で難度上げ。

## N-04 「ぜんぶで いくつ」｜基数性の芽
- **段/年齢**：s12（2歳9–11か月）
- **エンジン**：E06 操作型 → E01 選択
- **1画面ゴール**：数えた最後＝全体、と気づく
- **画面の動き**：ふうせん3個を1つずつタッチで数える → 「ぜんぶで 3！」と表示 → 「3」を選ぶ。
- **問題文**：「ぜんぶで いくつ？」
- **操作**：タップ→選択
- **見たい力**：基数性（cardinality）
- **ラウンド進行**：2個 → 3個

## N-05 「かぞえうた タッチ」｜数唱1〜5
- **段/年齢**：s09–s12（全体で楽しむ）
- **エンジン**：P02 リズム連打 の簡易版（ゆるい判定）
- **1画面ゴール**：歌に合わせて数字を順にタッチ
- **画面の動き**：かぞえ歌に合わせ 1→2→3→4→5 が順に光る。光ったらタッチ。
- **問題文**：「ひかった かずを タッチ！」
- **操作**：タイミングタップ（判定ゆるめ）
- **見たい力**：数唱・順序
- **メモ**：大画面（みんなで）でも、個別TBでも使える。
