# 数・論理 28段 各行 詳細（s01〜s28｜0歳〜6歳・3か月刻み）

各段で、数の11要素（数唱／計数1対1／基数性／subitizing／数字／量の比較／合成分解／順序数／加減／そろばん・位／論理）が**どの高さか**を1段ずつ記述。
表記は「要素：その段の中身」。空欄の要素はその段ではまだ扱わない。※年齢は目安・個人差大。可奈さんが確定を。

## 0歳 ── 数の「前」（感覚・操作の土台）

## 使い方
- **縦に見る**：一人の子が0→6歳でどう伸びるか（この表の上から下）。
- **横に見る**：ある段で、数の11要素がそれぞれどの高さか。
- **確定作業**：まず各段の「中心」と要素の高さを、可奈さんの実感で微調整 → 数の階段が完成。
- 次：各段の要素に **167ゲーム・カードを紐づけ**、**12週プラン**を段ごとに作る。
