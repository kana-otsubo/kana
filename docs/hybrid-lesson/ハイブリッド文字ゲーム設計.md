# ハイブリッド文字ゲーム 設計（大画面＋先生携帯＋子どもタブレット）

方針：育脳の型を参考にしつつ、**ハイブリッド専用**に作る。
＝**先生が大画面で提示 → 子どもが自分のタブレットでやる**（1人1台の育脳とはここが決定的に違う）。

## 1. ハイブリッドゲームの3画面モデル（全ゲーム共通）

| 画面 | 役割 |
|---|---|
| **大画面（TV）** | ①導入・お手本・問題の**みんなで見る提示** ②全員の**進み・正解の可視化** ③盛り上げ演出（ペル君）|
| **先生携帯（親機）** | 進行を握る：開始／問題を出す／ヒント／こたえ合わせ／次へ／もう一回／スキップ |
| **子どもタブレット（1人1台）** | 一人ひとりが**実際に解く**（タップ／なぞり）。正解でキラキラ |

**同期モード（`06`通し進行より）**
- **同期**：先生の「次へ」で大画面と全TBが揃って進む（一斉）。
- **個別**：子が自分のペースで解く（探究タイム的）。
- **ロック**：待機中は子TBをロック。特別な子だけ大画面映像をTBに個別共有。

**設計の芯**：「大画面＝みんなの場（お手本・共有・称賛）」「子TB＝自分の挑戦」。**先生は提示と間（ま）を作る**。

## 2. 見本フル仕様：A「あたまの おと さがし」（頭文字さがし）
育脳の型A（頭文字で始まるものを選ぶ）をハイブリッド化。まず作る1本目の推奨。

- **ねらい**：音韻（頭音）・文字認識 ／ **対象段**：s13前後（3歳）／ **エンジン**：E01 選択型
- **育つ力**：IQ（言語）・②EF（注意）

**① 大画面（TV）**
- ペル君が登場。「きょうは『り』の おと！」と**発音＋大きな文字「り」**を提示。
- お手本1問を**みんなで**：絵（りんご・ばなな・らっぱ…）が並び、ペル君が「りんご！」と正解を見せる。
- 全員がタブレットで解く間、大画面は**待ち受け＋みんなの進み**（◯人できた）を表示。
- 全員終了で「◯にん せいかい！」と称賛演出。

**② 先生携帯（親機）**
- ［開始］［問題を出す（「り」）］［音をもう一度］［ヒント］［こたえ合わせ］［次へ］［もう一回］
- 進み具合をリアルタイムで確認（誰が終わった／つまずき）。

**③ 子どもタブレット（1人1台）**
- 大画面と同じ絵が各自の画面に並ぶ → **「り」で始まる絵を1タップ**。
- 正解＝キラキラ＋ペル君の声。まちがい＝やさしく「もういちど」。
- 対象は大きく（最小64px）、1タップのみ。

**④ 同期・記録・演出**
- 同期モード：先生が［問題を出す］で**全TBに同時表示**。
- 記録：各児の正誤・時間・反応（にこにこ/むずかしい）。
- 声：ペル君／ルルちゃん／博士／おじいちゃん から選択。

**⑤ 難易度（段で上げる）**
- 頭音の近い選択肢を増やす／絵の数を増やす／清音→濁音→拗音。

## 3. A〜M をハイブリッド化するポイント（早見）
| 型 | 大画面（先生提示）| 子タブレット（各自）|
|---|---|---|
| A 頭文字さがし | 音＋文字を提示・お手本 | 頭音の絵を1タップ |
| B 同じ文字さがし | お手本の字を大きく | 同じ字を全部タッチ |
| C 半分の文字を戻す | 完成形をお手本 | 割れた字をドラッグ合体 |
| E かな書き歌（なぞり）| 書き歌の映像・筆順 | 自分で「さ」をなぞる |
| G 絵に合う言葉 | 絵を大きく提示 | 合う言葉を選ぶ |
| H 並び替えで言葉 | お題の絵を提示 | 文字を並べて単語に |
| I 正しい言葉 | 絵を提示 | 正しい表記を選ぶ |
| L 文字を読んで進む | 迷路の全体像 | 自分で読んで進む |
| M 買い物 | お店・お題を提示 | 言葉を読んで棚から選ぶ |

**共通**：大画面＝提示・共有・称賛／子TB＝挑戦。先生携帯で間を作る。同期/個別/ロックを切替。
