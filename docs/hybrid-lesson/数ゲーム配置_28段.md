## 気づき・ゲーム制作の宿題
- **s09〜s12（2歳台）に数ゲームがほぼ無い**（ゲームは2歳半＝s11以降から）。→ 2歳向けの数ゲーム（数え歌・ドッツ・多少）を**新規に作る**候補。
- **そろばんゲームが1本（H094）だけ**。→ そろばんの段（s21〜s28）用に増やす候補。
- **subitizing/量比較は3歳に厚い**（H154/H153/H110）＝基数性の土台としてよく揃っている。
- 5歳（s21〜）は**時計・測定・データ・カレンダー**が急に増える＝数の「生活応用」へ広がる設計になっている。
