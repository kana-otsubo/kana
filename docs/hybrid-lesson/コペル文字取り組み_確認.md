# コペルの「文字（もじ）」取り組み 確認まとめ

`materials/コペル教材_BOX1-12.zip` の各BOX×年齢プログラムから、**もじ**の取り組みを抽出。
→ 私の文字カリキュラム（`文字_カリキュラム_s01-s28`）を、コペルの実践に合わせて調整するための確認。

## 年齢ごとの実際の取り組み

### 1歳｜文字と音に出会う（もう始まっている）
- **もじの歌＆ひらがな絵本**（あいうえおの歌・行ごと）
- **もじさがし**（さ行…）／**ひらがなマッチング**／**ひらがなあわせ**（組文字）／**かるた5文字**
→ 1歳から「文字への興味・音・形のマッチング」を厚くやっている。

### 2歳｜組み文字・単語
- **もじさがし**／**ひらがなあわせ 組文字**（いろ・はな・ほし…）／**ひらがな絵本**／**ひらがなマッチング**
- **くみもじカルタ**（あさ・しま・きのこ／たこ・にんじん・みかん…）
→ 文字を組んで**単語**にする。読みの前に「文字＝音のまとまり」を体感。

### 3歳｜なぞりもじ（書きの入口）＋読み・弁別　※行を1周
各BOX＝1つの行。**なぞりもじの歌＋なぞりもじ／絵と単語のマッチング／正しい字は？／組み文字と単語**。
- 行の順：BOX1 さ→2 な→3 あ→4 わ→5 ま→**6 総合**（あいうえおの歌＆名前シール・かるた8文字）→7 や→8 か→9 は→10 た→11 ら→**12 総合**
→ **なぞり書きは3歳から**。読み（絵と単語）・弁別（正しい字は？）・構成（組み文字）を同時に。

### 4歳｜ひらがな書き＋カタカナ導入　※行を1周
- **ひらがななぞり文字歌＆書き**（3歳のなぞり→書きへ）／**もじ書きプリント**
- **カタカナなぞり文字歌＆書き**（サ行・ナ行…行ごと）
→ **書き**が本格化、**カタカナは4歳から**（なぞり書きで）。

### 5〜6歳
- プログラム上は「**もじのプログラム参照**」と別冊参照（漢字・文へ発展。詳細は別プログラム）。

## コペルの文字設計の特徴（学べる点）
1. **早い**：文字への興味・マッチングは**1歳から**。読みの前に「音・形・組み」を体感。
2. **書きは3歳（なぞり）→4歳（書き）**。カタカナは4歳。
3. **行を1周する12BOX構成**＝ちょうど**12週スパイラル**と同じ形！ 各BOX＝1つの行。
4. **同じ行で「歌・なぞり・読み・弁別・構成」を多面的に**（＝手を変え品を変え）。

## 私の文字カリキュラムの調整点（コペルに合わせる）
| 項目 | 私の初版 | コペル実際 | → 調整 |
|---|---|---|---|
| 文字マッチング・興味 | 2歳〜 | **1歳から** | 1歳に「もじの歌・ひらがなマッチング」を追加 |
| 組み文字（単語構成）| 3歳 | **2歳（くみもじカルタ）** | 2歳に前倒し |
| なぞり書き | 3歳後半(s15) | **3歳前半から全行** | 3歳(s13)から「なぞりもじ」 |
| カタカナ | 4歳後半〜5歳 | **4歳から（なぞり書き）** | 4歳(s17)にカタカナ導入 |
| 進め方 | 12週スパイラル | **12BOX＝行を1周** | 「12週＝12行」で一致（下記）|

### 文字の12週プラン＝「行を1周」（コペル式）
コペルの12BOX構成をそのまま12週に採用できる：
- 各週＝1つの行（さ→な→あ→わ→ま→[総合]→や→か→は→た→ら→[総合]）
- 各週の中で「歌・なぞり・絵と単語・正しい字・組み文字」を回す。
- 年齢で深さを変える：3歳=なぞり＋読み／4歳=書き＋カタカナ。
