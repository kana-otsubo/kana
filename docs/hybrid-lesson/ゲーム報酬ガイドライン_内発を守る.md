# ゲーム報酬ガイドライン ── 好奇心（CQ/PQ）を壊さない設計

ベンダー（システム会社）にも渡せる**1枚の設計指針**。ハイブリッドレッスンのゲームは、
「星が欲しいから」ではなく「**知りたい・やってみたいから**」子どもが動くように作る。

> **1行原則**：このゲームは「**ごほうびのため**」にやるのか、「**面白いから**」やるのか？ → **後者**にする。

---

## なぜ ── ご褒美の逆効果（過正当化効果）
- 「できたら星がもらえる」を続けると、子どもは **"星のため"に動くようになり、"面白いから"が消える**。
- ＝ IQ（できること）は上がっても、**CQ好奇心・PQ情熱（AI時代に最も育てたい力）が下がる**。
- ゲーム＝ポイント・星・ランキングが入りやすい形式だからこそ、**放置すると好奇心を削る設計になる**。ここを最初に決めておく。
- 裏づけ：自己決定理論（Deci & Ryan）＝内発的動機は **自律性・有能感・関係性** で育つ／外発報酬はそれを侵食する。

---

## 設計原則 ── ✕ を ◎ に置き換える
| ✕ 避ける（外発を煽る）| ◎ 置き換える（内発を守る）| 自己決定理論のどれ |
|---|---|---|
| クリアごとに星・コイン | **進み（自分の階段が伸びた）を見せる**・過去の自分と比べる | 有能感 |
| ランキング・友達と競争 | 競争なし。**自分の記録・成長の軌跡** | 有能感・自律性 |
| 「正解！」の報酬音が主役 | **発見の喜び**（隠れてたものが出る・変化する・つながる驚き）| 好奇心そのもの |
| 早さ・点数で煽る（タイマー競争）| **急かさない**・自分のペースで考える時間 | 自律性 |
| 全員同じ課題を一斉に | **選べる**（どれからやる？）| 自律性 |
| 難しすぎ／簡単すぎ | **一歩先の挑戦**（足場かけ＝s段・12週でちょうど良い難易度）| 有能感 |
| 先生・アプリが正解を先に言う | **問い返す・見守る**（「どうなると思う？」）| 自律性・関係性 |
| 失敗＝ブブー／減点 | 失敗＝**もう一回試せる**（試行そのものを歓迎）| 有能感 |

---

## 「発見の喜び」を作る4つの仕掛け（各ゲームに最低1つ）
子どもを引き込むのは**外の報酬ではなく、これ**。ゲーム仕様に1つは必ず入れる。

1. **驚き（サプライズ）**：予想と違う・隠れていたものが現れる・変化する。
2. **問い**：「どっちだと思う？」「次はどうなる？」＝答える前に考えたくなる。
3. **選択**：どれからやる／どの色・どのカード＝自分で決める余地。
4. **つながり（発見）**：バラバラが結びつく瞬間（音と字・数と量・組み文字が単語になる）。

## ハイブリッド3画面はこの原則に有利
| 画面 | 内発を守る役割 |
|---|---|
| **子タブレット** | **自分で選ぶ・自分のペース**（自律性）。急かさず、試行を歓迎。|
| **大画面（先生提示）** | **驚きと問い**を演出（「見てて…どうなる？」）。競争の場にしない。|
| **先生（携帯・進行）** | **見守る・問い返す・待つ**。正解を先に言わない。過程を認める。|

## ✕ してよい/だめ の線引き（誤解しやすい所）
- **進捗の可視化はOK**：スタンプ帳・階段が伸びる・「ここまで来た」＝**自分の成長**を見せるのは有能感を育てる（競争でなければ良い）。
- **一律の外的ごほうびはNG**：全ゲーム共通の「星○個でガチャ」等、**中身と無関係な報酬**は好奇心を外に逃がす。
- **ほめ方**：「上手！」「正解！」より **「どうやって思いついた？」「面白いね」**（過程・工夫をほめる＝グロースマインドセット）。
- **たまのお楽しみはOK**：毎回の報酬でなく、**節目のお祝い**（1周終わった等）は問題ない。日常の駆動をご褒美に頼らない。

## ベンダー確認チェックリスト（打ち合わせ用）
- [ ] 全ゲーム共通の「星／コイン／ガチャ」報酬を**主動線にしていないか**
- [ ] ランキング・対人競争の演出が**既定でONになっていないか**
- [ ] タイマー・早押しが**煽りになっていないか**（考える時間を奪わないか）
- [ ] 各ゲームに**「発見の仕掛け」（驚き・問い・選択・つながり）**が入っているか
- [ ] 進捗表示は**"自分の成長"**で、**他者比較でない**か
- [ ] 失敗時に**もう一度試せる**設計か（減点で終わらせないか）
- [ ] 子タブレットに**「選ぶ」「自分のペース」**の余地があるか
