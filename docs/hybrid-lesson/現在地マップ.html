03コペルより下がらない（照合の結論）

コペルの項目はほぼ覆えており、質はむしろ精密化。あと数点を足せば「網羅」。

覆えている・上乗せ

  • 歌・集中訓練・直観像・リンク・フラッシュ・かず・そろばん・図形・もじ・リトミック…全対応
  • 数・文字は28段で精密化、フラッシュは816整理済＝質は向上
  • 上乗せ：発表＋SST／粗大運動／個別ゲーム／世界水準の枠組み／3画面ハイブリッド

足す（虫食い）

  • 数：掛け算・百玉そろばん・マス計算・5とび10とび歌・音の数（洗い出し済／統合中）
  • 全体：暗唱・速読・連想ゲームを16場面に明示
  • → 足せば「コペルより下がらない」を担保

04これから（次の一手）

優先順。型はできているので、あとは展開と作り込み。

  1. 数の足す8点（掛け算・百玉そろばん・マス計算…）を各段・12週に完全統合
  2. 文字の12週プラン＋3歳の文字ゲーム
  3. 虫食い（暗唱・速読・連想）を16場面に追加
  4. 図形・リトミックほか他教科を、同じ型で（教室版で照合しつつ）
  5. ゲーム実装：ハイブリッド「あたまのおとさがし」から1本
  6. ベンダーすり合わせ（CSV列・28段の起点・枠方式・育つ力タグ…）
