# ハイブリッドレッスン 設計資料

幼児教室（コペル／コペルプラス）向けの新規プログラム **「ハイブリッドレッスン」** の設計一式。
「アプリでゲームを作り、それを使ってレッスンする」ための、教育設計・カリキュラム・フラッシュカード・ゲーム・アプリ仕様をまとめたもの。設計：大坪可奈

## いまの現在地（サマリー）
- ✅ **教育の土台が完成**：北極星（AI時代×世界水準）→ 28段階（0〜6歳・3か月）設計フレーム。
- ✅ **「数」が見本教科として一本通った**：要素分解 → 28段の各行 → 全段12週プラン → ゲーム配置 → 不足段の新規ゲーム仕様。
- ✅ **フラッシュカード**：分類（発注表の分野＝サブジャンル）・入れ方（枠方式）・816セットを整理。
- ✅ **ゲーム167本**を28段へ配置。**打ち合わせ資料**一式。
- ✅ **「文字」の背骨も作成**（2教科目）。⏭ 次：文字の12週・3歳文字ゲーム／図形ほか／2歳の数ゲーム実装／ベンダーすり合わせ → **作る作業は `作る作業_バックログ.md` に集約**。
