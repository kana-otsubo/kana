# ハイブリッドレッスン 設計資料

幼児教室（コペル／コペルプラス）向けの新規プログラム **「ハイブリッドレッスン」** の設計一式。
「アプリでゲームを作り、それを使ってレッスンする」ことを目的とした、カリキュラム設計・アプリ機能仕様・ゲームカタログをまとめたもの。

設計：大坪可奈

## 背景

- **コペル** … 幼児教室のプログラム
- **コペルプラス** … 発達障害の子ども向けプログラム
- **ハイブリッドレッスン** … 上記を土台に、大画面／個別タブレット／粗大運動／グループ活動を組み合わせ、
  デジタルゲームを使って進める新しいレッスン。既存の「乗り物の音クイズゲーム」（`src/`）はその試作ゲームの1本。

## 60分プログラムの構成（サンプル v0 より）

| Phase | 時間 | 内容 |
|---|---|---|
| 1 整える | 8分 | ごあいさつα波チューニング／チェックイン＆集中訓練法 |
| 2 インプット | 12分 | リベラルアーツインプット（FC・直観像・映像）／つなげる記憶（リンク法・暗唱）|
| 3 からだ | 12分 | リトミックブリッジ／サーキット粗大運動（3ステーション）|
| 4 考える＋つくる | 15分 | 探究タイム（個別タブレット育脳ゲーム）／つくる・あそぶ（創造タイム）|
| 5 つたえる＋おわる | 13分 | わたしの発表＆SST／そろばん＆クロージング |

モード配分：大画面 約22分 ｜ 個別タブレット 約8分 ｜ 粗大運動 約10分 ｜ グループ 約20分

## ベンダーとの開発スコープ（`01` シートより）

- **ゲーム規模**：育脳ゲーム 350本（うち50本完成済）／復習ゲーム（Kulabo風）5000本 想定
- **7月 MUST**：本部PC管理画面ログイン、プログラム一覧、プログラム作成/編集、大分類/小分類管理、CSVインポート、ユニーク管理番号(ID)、教室ホーム画面
- **9月以降**：セッションコード発行・デバイス接続、テンプレート機能、教室アプリの進行機能（順番入替・スキップ・ハプニング対策）、先生サポート情報のAI読み上げ 等
