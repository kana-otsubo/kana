# 発達28段階 設計フレーム ── どう分け、どう作るか

> 方針（可奈さん決定）：**0歳から3か月刻みで6歳まで＝28段階**を、**最新の研究を見ながらじっくり**作る。
> 段階を作り、実際のプログラムに落とし込む。

この文書は「**どんな形で分けていくか**」の設計図。以後、これに沿って1マスずつ埋めていく。

---

## 0. 段階の定義（s01〜s28｜0〜6歳・3か月刻み）

| 年齢 | 前半→後半（3か月ごと） |
|---|---|
| 0歳 | s01(0–2m) / s02(3–5m) / s03(6–8m) / s04(9–11m) |
| 1歳 | s05 / s06 / s07 / s08 |
| 2歳 | s09 / s10 / s11 / s12 |
| 3歳 | s13 / s14 / s15 / s16 |
| 4歳 | s17 / s18 / s19 / s20 |
| 5歳 | s21 / s22 / s23 / s24 |
| 6歳 | s25 / s26 / s27 / s28 |

※これまでの「24段階」は本定義（28段階・0歳起点）に統合。ゲーム167本（旧S5–S12）も本番号へ貼り替える。

## 1. 分け方の提案 ── 3つのレンズを「1つの表」に統合する

あなたが挙げた3つは、**別々の表ではなく、1つの表の“違う方向”**として組み合わせられる。

```
            ┌─────────── 時間軸：28段階（s01→s28） ───────────┐
            s01  s02  …                                   s28
能力項目 ┬ 粗大運動   [発達の姿/ねらい/手立て/評価] …
（縦） │ 言語        …各マスを埋める…
        │ 数・論理
        └ …
        ↑ 各項目には「3本柱・7要素・育つ力」タグが付く（横断）
        ↑ 各マスは「月齢の発達マイルストーン（研究）」で裏づける（土台）
```

- **横（列）＝28段階**：時間の軸。「いつ」。
- **縦（行）＝能力項目**：育てる力の軸。「何を」。（§3）
- **タグ＝3本柱・7要素・育つ力**：価値の軸。「なぜ／どんな力か」。全項目に横断的に付ける。（§4）
- **土台＝月齢の発達**：各マスの根拠。「研究でこの月齢に何ができるか」。（§5）

→ この1枚で、あなたの3つの視点が**全部同時に**見える。どれかを選ぶ必要はない。

## 2. 1マスの中身（記入テンプレート）

「能力項目 × 段階」の各マスに、次を書く。これが最小単位。

| 欄 | 内容 | 例（数 × s13＝3歳0か月）|
|---|---|---|
| **発達の姿** | その月齢で自然にできること（研究の裏づけ）| 「3までなら正しく数える（1対1対応）」|
| **ねらい** | この段で育てたい具体 | 1〜5の数唱と実数の対応 |
| **手立て** | レッスンの活動・ゲーム・カード | ドッツ／かぞえうた／ゲームH041 |
| **評価の目安** | できたの見取り | 5個を指さして数えられる |
| **タグ** | 3本柱・7要素・育つ力 | IQ／②EF／数量空間 |

## 3. 能力項目（縦軸）の案 ── 発達領域でまとめる

「育てる力」を、発達研究の**領域**でグループ化し、その下にレッスン項目を置く（2層）。
0〜6歳を通して一貫。※これはたたき台。可奈さんが増減・改名してOK。

| 発達領域 | レッスン項目（この下にぶら下がる）|
|---|---|
| **運動（粗大）** | 姿勢・移動・リトミック・粗大運動・バランス |
| **運動（微細・巧緻）** | 手指・なぞり・はさみ・折り・書字の土台 |
| **言語・コミュニケーション** | 事物名称・やりとり・文字・暗唱・英語 |
| **認知・思考** | 基礎概念・図形・IQ・探索・百科事典（知識）|
| **数・論理** | 数・そろばん・数量空間 |
| **記憶・注意** | 直観像・右脳・リンク法・集中(EF) |
| **社会性・情動** | SST・自己/感情・発表・4C's |
| **感覚・身体感覚** | 感覚遊び・インテロセプション（呼吸/体感）|
| **音楽・表現** | 歌・リトミック・リズム |
| **創造・自立** | ごっこ/創造・生活動作・自立 |

## 4. 横断タグ（価値の軸）

各項目・各マスに付ける。「この活動は何の力か」を明示する。

- **3本柱**：IQ（学びの土台と思考）／EQ（自分を知り整える）／SQ（人とつながる）
- **7要素**：①エージェンシー ②EF ③身体性認知 ④インテロセプション ⑤グロースマインドセット ⑥ごっこ遊び ⑦4C's
- **育つ力／ねらい**：（Kulabo25領域とも対応づけ可）→ `育つ力リスト.md`

## 5. 参照する研究・枠組み（“最新の研究を見ながら”の土台）

各マスの「発達の姿」を、次の枠組みで裏づける（段を作るたびに該当を引く）。

- **発達マイルストーン**：WHO / CDC 乳幼児マイルストーン、遠城寺式・KIDS（日本）、Denver II
- **認知・数・言語**：ピアジェ、ワーキングメモリ（Baddeley）、数認知（subitizing / Dehaene）、語彙爆発・MacArthur-CDI
- **実行機能(EF)・自己制御**：Harvard Center on the Developing Child、Diamond
- **社会情動(SEL)・非認知**：CASEL、Heckman
- **マインドセット**：Dweck
- **世界標準**：OECD Learning Compass 2030、IB PYP、21世紀スキル(4C's)

## 6. 作る順番（じっくり進める計画）

1. **この設計フレームに合意**（分け方＝§1、項目＝§3、テンプレ＝§2）。
2. **1領域・1項目を選び、s01→s28 の全マスを研究付きで埋める**（例：まず「数・論理」）。
3. 埋まった段階に、**手立て（ゲーム・カード）を紐づける**（167本や新規）。
4. 次の項目へ。**縦に1本ずつ**育てていく。
5. ある段階の各項目が揃ったら、**その段の週プログラム**に落とし込む。

---

## 6.5 段の中の「12週」をどう作るか ── 飽きさせない設計

1つの段＝約3か月＝**毎週来るので約12回**。ここを「同じこと12回」にすると幼児は飽きる。かといって「12回バラバラ」も土台が育たない。

**原理：ねらいは1本・見せ方と難易度は毎週変える（＝手を変え品を変え＋スパイラル）。**
- 幼児は**繰り返しで習得**（安心・定着）し、**新しさで集中が続く**。両方を満たすのが「反復＋変化」。
- これは既に実践済み：**週間フラッシュカードの「枠は同じ・カードは毎週変わる」**がまさにこれ。全項目に広げる。

**段（3か月）を2層で設計する：**
| 層 | 何を決めるか | 変化の速さ |
|---|---|---|
| 発達段階（28段）| 今この子に合う“ねらい” | ゆっくり（3か月）|
| 週プログラム（12回）| 同じねらいを、12通りの見せ方で少しずつ上げる | 毎週 |

**12週の作り方（例：s13「1〜5の対応」）**
| 週 | 段階 | 変える所 |
|---|---|---|
| 1–2 導入 | ねらいに出会う | ドッツ・新しいかぞえ歌 |
| 3–4 実物 | 手で数える | おはじき→積み木（教材替え）|
| 5–6 記号 | 数字と実数を結ぶ | ゲームH041・身の回りの物 |
| 7–8 順序 | 5とび・順番 | すうじのせんろ（ゲーム）|
| 9–10 応用 | 生活で使う | お店やさんごっこ（⑥ごっこ）|
| 11 挑戦 | 少し上（6の芽）| ⑤グロースマインドセット |
| 12 発表 | できたを確認 | 発表・SSTと統合 |

→ ねらい1本／毎週 教材・文脈・遊び方・難易度が変化／時々 復習。
さらに1回の中で**数・文字・図形・体…と多項目を回す**ので単調にならない。
