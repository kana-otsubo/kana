Lesson Screen Specification

レッスン15場面 画面仕様

幼児教室の1コマを、大画面ディスプレイ・先生の携帯・子どもタブレットの3台で進行するための仕様です。場面ごとに、何を映し、先生が何を操作し、子どもが何をし、何を記録するかをまとめています。

01 / Devices機器の役割

大画面ディスプレイ

子ども全員が見る画面。動画・カード・問題・正解などを表示する。

先生の携帯

進行の操作。大画面に何を出すかを制御し、先生用のカンペ・進行メモも表示する。

子どもタブレット

子どもが個別に使う端末。場面ごとに、ロック／操作可／画面共有を切り替える。

レッスンは15場面を上から順に進める。先生の操作で、場面のスキップ・やり直しができる。

02 / Common共通仕様

進行

  • 場面は原則、番号順に進む。先生の携帯から「次の場面へ」「前の場面へ」「この場面をスキップ」ができる。
  • 場面の中の進行（次のカード、次の問題など）も先生の携帯から操作する。
  • 自動で進む場面は、速度を先生の携帯から変更できる。

子どもタブレットの状態

状態内容
ロック触っても反応しない。画面は待機表示、または大画面と同じ表示。
操作可その場面で必要な操作（タッチ・ドラッグ・選択）ができる。
画面共有大画面と同じ内容を手元にも出す。必要な子だけ個別にONにできる。
  • ロック中に子どもが触っても、エラー表示や進行の中断を起こさないこと。
  • 先生の携帯から、特定の子だけ画面共有をONにできること。

音声キャラクター

音声は ペル君／ルルちゃん／博士／おじいちゃん の4種類から選ぶ。場面ごと・カードごとに設定でき、先生の携帯から途中変更もできる。

記録

  • 記録は、先生が操作しなくても自動で残ることを基本とする。
  • 子どもが答えられない、声だけで答えた等の場合は、先生の携帯から代理入力できる。
  • 1コマ終了時に、その日の記録を保護者レポートとしてまとめて送信できる。

教材の差し替え

  • 文字教材・図形教材・レッスンタイムの取り組みは、週ごと／BOXごとに差し替える。
  • 差し替えは管理画面から教材を選ぶ操作で行えること（プログラム修正なしで変更できること）。
