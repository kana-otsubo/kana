## 1. 今回の目的とゴール

### 1.1 目的

今回のデモで示したいのは「カードが画面に表示されること」ではない。

> **さまざまな知識がテンポよく次々と提示され、子どもが惹きつけられて見続けられること。**
> **さらに、先生が操作に追われず、実際のレッスンとしてスムーズに進行できること。**

この 2 点が達成された状態を「完成」と定義する。

### 1.2 完成条件（受け入れ基準）［必須］

次回デモにおいて、以下がすべて満たされること。

1. **先生役が操作し、子どもに見せるつもりで、フラッシュカード部分を最初から最後まで通して再生できる。**
   **百科事典だけでなく、ことわざ・四字熟語・俳句・百人一首などを含めた全カード種別が、一つの流れとして通ること**（§7.1）。
2. 通し再生の途中で、設定画面・選択画面・エラー・読み込み待ちによる**中断が一度も発生しない**。
3. 音声とカード表示のズレが体感で気にならない（§6 の許容値内）。
4. **先生読みモードのとき、先生が「次へ」を押しながら、そのカードの文字を無理なく読める。**
   自動音声モードのときは、「次へ」を押さずに進む（§7.2）。
5. **通し再生の間、先生が端末の音量を変える必要がない**（§6.1）。動画・歌・フラッシュカードの間で音量差を感じない。

**「システムが動く」ことは完成条件ではない。レッスンとして通せることが完成条件である。**

## 2. 用語定義

| 用語 | 定義 |
| --- | --- |
| カード | 1 枚の提示単位。画像／文字＋音声で構成される |
| カード種別 | 百科事典・ひらがな・ことわざ・四字熟語・反対語・俳句・百人一首・反対語の歌など（§7.1） |
| セット（デッキ） | 連続再生される 1 まとまり。例：「百科事典・動物 10 枚」 |
| ジャンル | 百科事典セット内の分類。動物・乗り物・果物・職業・第 5 ジャンル |
| 通常カード | シンプルで瞬時に認識できる標準のカード |
| レアカード | セット後半に 1 枚だけ配置し、注意を引き直す役割のカード |
| セッション | 全カード種別を通した一連の流れ（§7.1） |
| 表示方法（トランジション） | カードが画面に現れる際の見せ方（瞬時表示・ズーム等） |

## 3. 百科事典カード

### 3.1 制作枚数［必須］

| ジャンル | 枚数 | うちレアカード |
| --- | --- | --- |
| 動物 | 10 | 1 |
| 乗り物 | 10 | 1 |
| 果物 | 10 | 1 |
| 職業 | 10 | 1 |
| 第 5 ジャンル（下記 3.2） | 10 | 1 |
| **合計** | **50** | **5** |

**各ジャンルは 10 枚を 1 セットとし、途中で止まらず連続提示できること。**
セット内での一時停止・選択・確認ダイアログは一切設けない。

### 3.2 ジャンル構成［必須］

**動物・乗り物・果物・がっき の 4 ジャンル、合計 40 枚とする。**

**職業カードは作らない。** 職業ジャンルは廃止し、がっき（楽器）に置き換える。

### 3.3 レアカードの配置ルール［必須］

- 各ジャンル 10 枚のうち、**5 枚目以降のどこかに 1 枚だけ**配置する。位置は問わない。
- 1 セットにレアカードは **1 枚のみ**。2 枚以上入れない。
- 位置はデータ側で決まり、コードに直書きしない。

### 3.4 レアカードの設計［必須］

**レアカードは、子どもが楽しみにするカードである。**
「10 枚に 1 枚、特別なカードが出る」というゲーム性を持たせること。

#### 基本の考え方：静・静・静……→ 変化！

**常に派手にするのではない。**
通常の 9 枚は統一された図鑑調で、静止したまま、同じテンポで淡々と見せる。
そして 5 枚目以降のどこかで、**突然そのカードだけが動き、音が鳴る。**

```
静 → 静 → 静 → 静 → 静 → 静 → 【変化！】 → 静 → 静
```

**幼児の注意を引くのは「予想していた流れから少し外れる変化」である。**
9 枚が完全に静かで統一されているほど、1 枚の変化が効く。**通常カードを揃えることが、レアカードを効かせる前提条件になる。**

#### 予兆は出さない［必須］

- **レアカードの前に予告・前触れを出さないこと。** 「次に来るぞ」と分かった時点で、驚きも変化も失われる。
- 直前のカードまで、完全にいつもどおりに進める。

#### 変化の内容［開発側に任せる］

**変化の内容（何がどう動き、どんな音が鳴るか）は、開発側で決めてよい。**
カードごとに違う変化にすること。全ジャンル共通の演出テンプレートにしない。

参考：ぞうなら「鼻を上げて **パオーン！**」、しょうぼうしゃなら「ライトが光る ＋ サイレン」、すいかなら「パカッと割れて中が見える」。

**レアカードの題材は、めずらしいものである必要はない。**
むしろ、子どもがよく知っているもののほうが「いつもと違う」が伝わりやすい。**変えるのは題材ではなく、振る舞いである。**

#### 変化の制約［必須］

| 項目 | 規定 |
| --- | --- |
| 回数 | **1 回だけ。ループさせない** |
| 長さ | 動きは 0.6 秒以内、音は 0.8 秒以内 |
| 音 | 読み上げ音声と**重ねない**。読み上げの後に鳴らす |

**レアカードの表示時間は、通常カード +1.0 秒程度。**

#### 禁止事項

- レアカードの前に予告・前触れを出す。
- 変化を繰り返す・ループさせる。
- **通常カードにも動きを付ける**（通常カードは完全に静止。これが崩れるとレアが効かない）。

### 3.5 カード画像の制作規格［必須］

#### 画面の使い方：ディスプレイ全体・境目なし

**画像はディスプレイ全体を使って表示する。カードとの境目を作らない。**
画面の中に「カード」という囲みが見える状態にはしない。枠・角丸・影・余白の帯を一切作らず、画像が画面の端まで届くこと。

#### 色：明るい・はっきり・少数

**白〜ごく薄い背景 ＋ 彩度の高すぎない鮮やかな色。**

| 項目 | 規格 |
| --- | --- |
| 背景 | **白〜ごく薄い単色**（`#FFFFFF`〜`#FAF8F5`）。**全カード共通**。画面の端まで塗り切る |
| 主役の色 | 赤・黄・青・緑・オレンジなど、**幼児が区別しやすい色**。彩度は高すぎないこと（目に刺さる蛍光色は使わない） |

**例：「りんご」の場合**

```
白い背景 ＋ 大きな赤いりんご
```

これくらいがフラッシュカードには向いている。背景まで色を付けない。
語の「りんご」は画面に出さず、音声と先生の読み上げで伝える（§3.6）。

**背景色をカードごとに変えないこと。** 背景が変わると連続再生時にちらつきの主因となる。
フルブリード表示では画面全体が背景色で埋まるため、色が変わると**画面全体が変化する**ことになり、影響がさらに大きくなる。

#### 画像のタッチ：実物がすぐ分かる、少し柔らかい図鑑イラスト

**「リアルすぎず、キャラクターすぎず」。**
写真そのものより少し温かく、しかし漫画化しすぎない。

| 項目 | 規格 |
| --- | --- |
| 特徴の正確さ | **体の形・鼻・耳など、その対象の特徴を正確に描く**（ぞうなら鼻の長さ・耳の大きさ・体の形） |
| 輪郭 | **明確**。にじませない |
| 陰影 | **少なめ**。強い影・複雑なグラデーション・細かいテクスチャは使わない |
| 背景の情報 | **余計なものを入れない。** 木・草・空・地面などは基本的に描かない |
| 顔 | **過度にキャラクター化しない。** 目を極端に大きくしない、擬人化しない、表情を付けすぎない |
| 写真 | 使わない |
| 向き | 動物・乗り物は原則、左向きまたは正面に統一 |

**判定基準**

> **子どもがあとで本物を見たときに、「これがゾウ」と結びつくか。**

百科事典カードなので、「かわいい」だけでは足りない。**実物と結びつくことが目的**である。この基準で 1 枚ずつ確認すること。

#### 「境目を作らない」の適用範囲

- カードの周囲に枠線・影・角丸を付けない。
- 画面の縁に色帯・余白を作らない。
- 前のカードと次のカードの間に、境界を感じさせる線・帯・暗転を挟まない。

### 3.6 子ども用画面に文字を出さない［必須］

**百科事典カードでは、子どもが見る表示画面に文字を表示しない。絵だけを見せる。**

- カード画像に文字を焼き込まない。画面上にも文字を重ねない。
- 語は**音声（§6）と先生の読み上げ**で伝える。
- 文字は**先生用の操作画面にのみ表示する**。
- 理由：絵そのものに注意を集中させるため。文字が入ると視線が分散し、実物との結びつき（§3.5 の判定基準）が弱くなる。

#### 例外：文字が主役のカード種別

**ひらがな・ことわざ・四字熟語・俳句・百人一首**は、文字そのものがカードの中身である。
これらは**子ども用画面にも文字を表示する**。各種別の表示は §4・§5 に従う。

| 種別 | 子ども用画面の文字 |
| --- | --- |
| 百科事典 | **出さない**（絵だけ） |
| ひらがな | 出す（文字が中身） |
| ことわざ | 出す（文字が中身） |
| 四字熟語 | 出す（文字が中身） |
| 俳句 | 出す（文字が中身） |
| 百人一首 | 出す（文字が中身） |

**判断の基準は「絵が主役か、文字が主役か」である。** 絵が主役の種別では文字を出さない。

| --- | --- | --- |
| 「お」の語 | おさる | **おちば** |

- 画像・音声・テキストラベルの**すべて**を差し替えること。
- 「おさる」の素材はデータから削除し、参照が残らないようにする。

## 5. ことわざカード

### 5.1 位置づけ

ことわざカードは「**あいうえお順にことわざを覚える**」カードである。ことわざ単体を覚えるカードではない。

### 5.2 音声の読み上げルール［必須］

**必ず、該当するひらがなを 1 音はっきり読んでから、ことわざを読む。**

| 正しい形 |
| --- |
| 「**あ！** 足元に火がつく」 |
| 「**い！** 一寸の虫にも五分の魂」 |
| 「**う！** 嘘八百」 |

**禁止する読み方**

| 禁止 | 理由 |
| --- | --- |
| 「足元に火がつく、足元に火がつく」 | 同じ文言の重複読み。冗長でテンポを損なう |
| 「一寸の虫にも五分の魂」（いきなり本文から） | 頭のひらがなが聞こえず、あいうえお順の学習にならない |

### 5.3 音声の構成［必須］

```
［頭のひらがな 1 音（強め・はっきり）］ → ［間 0.4 秒］ → ［ことわざ本文 1 回］
```

- 頭のひらがなは、本文よりやや大きめ・はっきりと発音する。
- 本文の読み上げは **1 回のみ**。繰り返さない。
- このルールを**全ことわざカードに例外なく適用**する。

### 5.4 画面表示

- 音声の頭のひらがな発声と、画面のひらがな表示の**開始タイミングを一致**させる。

## 6. 音声仕様［必須］

### 6.1 音量の統一［必須・最優先］

**現状の問題：動画と歌が急に大きくなり、フラッシュカードの音声との差がある。**
レッスン中に先生が端末の音量を調整せざるを得ない状態になっている。これは §1.1 の「先生が操作に追われず、レッスンとしてスムーズに進行できること」に直接反する。

> **目標：レッスンの最初に音量を 1 回決めたら、最後まで触らなくてよい状態にする。**

#### 適用範囲

**この基準はフラッシュカードだけでなく、レッスン内で再生されるすべての音に適用する。**
フラッシュカード側だけを揃えても、動画・歌との差は解消しない。

| 対象 | 基準ラウドネス |
| --- | --- |
| フラッシュカードの読み上げ音声 | **-16 LUFS**（integrated） |
| 歌 | **-16 LUFS**（integrated） |
| 動画の音声 | **-16 LUFS**（integrated） |
| 効果音（レアカードの変化音など） | **-18 LUFS**（突発音のため、やや控えめにする） |
| すべての素材に共通 | **True Peak −1.0 dBTP 以下** |

#### 測定・制作のルール

- **ラウドネス（LUFS）で揃える。ピーク正規化だけで揃えない。**
  ピーク正規化（波形の最大値を 0dB に合わせる方法）は、**今回の音量差の典型的な原因**である。歌や動画は音が詰まっているため、ピークを揃えると体感音量が読み上げ音声より大きくなる。
- 歌は**ボーカルと伴奏の合計**で測る。ボーカルだけで測らない。
- 動画は**音声トラックを抽出して測る**。書き出し時の再エンコードで音量が変わっていないか、書き出し後にもう一度測る。
- 2 秒未満の短い素材（カード 1 語の読み上げなど）は integrated の測定が不安定になる。**同一話者・同一収録条件で録ったうえで**、測定値を添えて提出する。
- 測定ツールは問わない（`ffmpeg -af loudnorm` 等で可）。ただし**全素材を同一の方法で測ること**。

#### 実装側のルール

- **種別ごとの再生ゲインを設定ファイルで持つ**（例 `volumeGain`）。素材を作り直さずに微調整できるようにする。
- **再生時に自動ゲイン調整（AGC）やリミッターをかけない。** 素材の段階で揃える。実行時の自動調整は、静かな部分を持ち上げてノイズを目立たせ、テンポの妨げになる。
- 端末の音量は先生が最初に 1 回決める。**レッスン中に音量 UI を出さない。**

#### 検収方法

1. **全素材の測定値一覧を提出する**（ファイル名／integrated LUFS／True Peak の表）。フラッシュカード音声・歌・動画・効果音のすべてを含めること。
2. **通し再生で、端末の音量に触れずに最後まで行けることを確認する。** これが合格の判定である。

## 7. フラッシュカード全体の操作【最重要】

### 7.1 レッスンの流れと対象カード種別［必須］

**フラッシュカードは、すべてのカード種別を一つの流れとして一気に流していく。**
百科事典はその中の 1 種別にすぎない。**百科事典を特別扱いしない。**

```
百科事典 → ひらがな → ことわざ → 四字熟語 → 反対語 → 俳句 → 百人一首 → 反対語の歌
```

**ここまでを一気に流す。**

#### 対象カード種別

| 種別 | 1 セットの構成 | カードの中身 |
| --- | --- | --- |
| 百科事典 | 10 枚 × 4 ジャンル | 絵 |
| ひらがな | 行ごと | 文字 ＋ 語 ＋ 絵 |
| ことわざ | あいうえお順 | 頭のひらがな ＋ ことわざ |
| 四字熟語 | あいうえお順 | 四字熟語 ＋ 絵または文字のみ |
| 反対語 | 対で 1 枚 | 語 ＋ 対になる語 |
| 俳句 | 句ごと | 句 ＋ 絵 |
| 百人一首 | 歌ごと | 上の句 ＋ 下の句 |
| 反対語の歌 | 曲ごと | 歌 |

種別は今後も増える。**種別が増えても、再生の仕組みを作り直さずに追加できる構造にすること。**

### 7.2 再生モード［必須］

**2 つのモードを持つ。**

| モード | 進み方 | 音声 | 先生用画面の文字 |
| --- | --- | --- | --- |
| **自動音声モード** | **「次へ」を押さずに自動で進む** | 収録音声が読み上げる | 不要 |
| **先生読みモード** | 先生がスマホ側で「次へ」を押して進める | 収録音声は鳴らさない | **必要** |

- モードは**セッション定義（JSON）で指定する**。先生がレッスン中に切り替える UI は出さない。
- **自動音声モードでは、カード間もセット間も「次へ」を押さずに進む。**
- **先生読みモードでは、先生が読みながら「次へ」を押して進める。**
