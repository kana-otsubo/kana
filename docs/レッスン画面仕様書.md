# レッスン画面 仕様書

作成日: 2026-08-18
対象: 1コマ分のレッスン（全15場面）

---

## 1. 目的と全体像

幼児教室の1コマのレッスンを、3つの機器を連動させて進行する。

| 機器 | 役割 |
|---|---|
| 大画面ディスプレイ | 子ども全員が見る画面。動画・カード・問題・正解などを表示する |
| 先生の携帯（操作端末） | 進行の操作。大画面に何を出すかを先生が制御する。先生用のカンペ・進行メモも表示する |
| 子どもタブレット | 子どもが個別に操作する端末。場面ごとに「ロック」「操作可」「大画面と同じ画面を共有」を切り替える |

レッスンは15場面を上から順に進める。先生の操作で、場面のスキップ・やり直しができる。

---

## 2. 共通仕様

### 2.1 進行

- 場面は原則、番号順に進む。先生の携帯から「次の場面へ」「前の場面へ」「この場面をスキップ」ができる。
- 各場面の中の進行（次のカード、次の問題など）も先生の携帯から操作する。
- 自動進行する場面では、速度を先生の携帯から変更できる。

### 2.2 子どもタブレットの状態

各場面に、次の3つのいずれかを設定する。

| 状態 | 内容 |
|---|---|
| ロック | 触っても反応しない。画面は待機表示または大画面と同じ表示 |
| 操作可 | その場面で必要な操作（タッチ・ドラッグ・選択）ができる |
| 画面共有 | 大画面と同じ内容を子どもの手元にも出す。必要な子だけ個別にONにできる |

- ロック中に子どもが触っても、エラー表示や進行の中断を起こさないこと。
- 先生の携帯から、特定の子だけ画面共有をONにできること。

### 2.3 音声キャラクター

音声は次の4種類から選ぶ。場面ごと・カードごとに設定でき、先生の携帯から途中変更もできる。

- ペル君
- ルルちゃん
- 博士
- おじいちゃん

### 2.4 記録

- 記録は、先生が操作しなくても自動で残ることを基本とする。
- 子どもが答えられない、声だけで答えた等の場合は、先生の携帯から代理入力できる。
- 記録項目の一覧は「6. 記録項目」を参照。
- 1コマ終了時に、その日の記録を保護者レポートとしてまとめて送信できる。

### 2.5 教材の差し替え

- 文字教材・図形教材・レッスンタイムの取り組みは、週ごと／BOXごとに差し替える。
- 差し替えは、システムの管理画面から教材を選ぶ操作でできること（プログラム修正なしで変更できること）。

## 3. 場面ごとの仕様

### No.1 はじまりのうた

| 項目 | 内容 |
|---|---|
| 大画面 | 歌のお姉さんの動画を再生 |
| 先生の携帯 | 開始／一時停止／再開／子ども画面共有のON・OFF |
| 子どもタブレット | ロック（切り替えで画面共有も可） |
| 記録 | なし |
| 素材 | 既存データから |
| 備考 | 誤タッチしてもエラーにならないこと |

### No.2 お名前呼び

| 項目 | 内容 |
|---|---|
| 大画面 | 名前カードを表示（例：大坪可奈 → おおつぼ かな）。あわせて気分アイコンを表示 |
| 先生の携帯 | 次の子へ／もう一回呼ぶ／先生が代理入力／スキップ／質問を選ぶ（例：好きな果物は？） |
| 子どもタブレット | 操作可。自分のタブレットで今日の気分をタッチする（例：にこにこ 等） |
| 記録 | 出席／気分／今日頑張ったこと／好きなもの／補助の有無 |
| 素材 | 新規作成が必要 |
| 備考 | 声で答えた内容は先生が記録する。名前は漢字表記とひらがな表記の両方を持つ |

### No.3 深呼吸・イメージトレーニング

| 項目 | 内容 |
|---|---|
| 大画面 | 「すう／はく」を目で見て分かるアニメを表示する。風船がふくらむ／しぼむ、または丸が大きくなる／小さくなるを繰り返す。最後に短いイメージ指示を出す |
| 先生の携帯 | 開始／次へ／音声のON・OFF（音声を切って先生の声で誘導する場合がある） |
| 子どもタブレット | ロック（画面は見てよいが、操作は不要） |
| 記録 | なし |
| 素材 | 動画素材から |
| 備考 | 呼吸の音声・BGM・画面アニメを同期させる。年齢別に時間を短くできること |

### No.4 直観像

| 項目 | 内容 |
|---|---|
| 大画面 | 見せる → 消す → 見せる → 消す → 回答画面 → 正解表示、の順に進む |
| 先生の携帯 | 表示／消す／もう一回見せる／回答へ／正解表示／次へ。あわせて子どもの様子をタップで記録 |
| 子どもタブレット | 操作可。子どもが絵をドラッグして置く。正解の位置は光る。一定時間が経つとヒントが光って出る。置きなおせば正解として扱う |
| 記録 | 解答時間／子どもの答え／正誤（自動で記録する） |
| 素材 | 既存レッスンから |

### No.5 リンクカード

| 項目 | 内容 |
|---|---|
| 大画面 | カードを順番に表示し、物語やつながりを見せる |
| 先生の携帯 | 次へ／戻る／最初から／音声自動のON・OFF／先生カンペ表示 |
| 子どもタブレット | ロック |
| 記録 | なし |
| 枚数 | 10〜30枚の可変。回ごとに枚数が変わる |
| 備考 | フラッシュカードと同じカードデータで扱う |

### No.6 フラッシュカード

| 項目 | 内容 |
|---|---|
| 大画面 | 各カテゴリのカードを表示。高速・中速・先生進行の切り替えができる |
| 先生の携帯 | 開始／停止／再開／スキップ／速度変更／声の種類変更 |
| 子どもタブレット | ロック（見る・聞く）。必要な子だけ個別に画面共有できる |
| 記録 | なし |
| 備考 | 音声とカードめくりを別々に制御する（下記） |

進行モードは、デッキごと・カードごとに次の4つから設定する。

1. 完全自動（音声もめくりも自動）
2. 音声のみ自動（めくりは先生）
3. めくりのみ自動（音声は先生の声）
4. 先生進行（両方とも先生の操作）

デッキ一覧は「4. フラッシュカードのデッキ一覧」を参照。

### No.7 今月の歌

| 項目 | 内容 |
|---|---|
| 大画面 | 今月の歌の映像と歌詞を表示 |
| 先生の携帯 | 開始／一時停止／再開／次へ |
| 子どもタブレット | ロック。必要な子だけ画面共有できる |
| 記録 | なし |
| 備考 | 歌詞と音声を同期させる。月ごとに差し替える |

### No.8 レッスンタイム

| 項目 | 内容 |
|---|---|
| 大画面 | 取り組みを3つ、順番に提示する |
| 先生の携帯 | 取り組み1／2／3 それぞれの開始・終了・次へ。先生用の進行メモを表示 |
| 子どもタブレット | 必要な取り組みのみ操作可。それ以外はロック |
| 記録 | 取り組みごとの実施状況／補助の有無 |
| 備考 | 内容はBOXごと・週ごとに差し替える |

### No.9 もじ

| 項目 | 内容 |
|---|---|
| 大画面 | 文字プログラムを表示 |
| 先生の携帯 | 開始／次へ／記録 |
| 子どもタブレット | 操作可。なぞる・選ぶ・答える等、教材に応じた操作 |
| 記録 | 実施状況／補助の有無 |
| 教材 | ひらがな書きプリント（あ行）。白抜き文字をなぞる形式。印刷用データあり |
| 備考 | 文字教材は週ごとに差し替える。「文字」の1枠として管理する（2種類に分けない） |

### No.10 かずのうた

| 項目 | 内容 |
|---|---|
| 大画面 | 数の歌の動画・歌詞・数字を表示 |
| 先生の携帯 | 開始／一時停止／次へ |
| 子どもタブレット | ロック。必要に応じて数字をタッチできる |
| 記録 | なし |
| 備考 | 歌と数字表示を同期させる |

### No.11 数プログラム

| 項目 | 内容 |
|---|---|
| 大画面 | 数の課題画面。実物教材を使う前提で、見本・指示・答えを表示 |
| 先生の携帯 | 開始／問題表示／正解表示／次へ／記録 |
| 子どもタブレット | 実物教材を使う。必要なときだけタッチで回答 |
| 記録 | 教材名／正誤／補助の有無／子どもの反応 |
| 教材 | 卵（実物教材） |

### No.12 図形

| 項目 | 内容 |
|---|---|
| 大画面 | 図形の見本・問題・正解を表示。教材を使う指示を出す |
| 先生の携帯 | 開始／問題表示／正解表示／次へ／記録 |
| 子どもタブレット | 実物教材を使う。必要なときだけ選択・タッチ |
| 記録 | 教材名／正誤／補助の有無 |
| 教材 | 積み木（実物教材）。お手本の図形を表示する |
| 備考 | 図形教材は週ごとに差し替える。立体と平面で表示方法を分けられること |

### No.13 そろばん

| 項目 | 内容 |
|---|---|
| 大画面 | そろばんの画面（0〜20） |
| 先生の携帯 | 開始／停止／次へ |
| 子どもタブレット | ロック、または見てまねる |
| 記録 | なし |
| 備考 | 「そろばんの歌」として歌で扱う形と、0〜20の操作課題として扱う形がある。どちらにするかは要確認（7章参照） |

### No.14 エンジョイタイム

| 項目 | 内容 |
|---|---|
| 大画面 | 活動内容に応じて、動画・BGM・説明画面を表示 |
| 先生の携帯 | 活動を選ぶ（リトミック／粗大／実験／バスゲーム） |
| 子どもタブレット | ロック。活動により個別参加・タッチ可 |
| 記録 | 活動の種別／参加状況 |
| 今回の実施 | リトミック／実験 |
| 備考 | 名称は「エンジョイタイム」に統一する |

### No.15 終わりの歌

| 項目 | 内容 |
|---|---|

## 5. カードデータの項目

カードはリンクカード（No.5）とフラッシュカード（No.6）で共通のデータとして管理する。

### 5.1 デッキが持つ項目

| 項目 | 内容 |
|---|---|
| デッキ名 | 画面と管理画面に表示する名前 |
| 種別 | 絵カード／文字カード／対のカード／文カード |
| 枚数 | そのデッキに入れる枚数 |
| 進行モード | 完全自動／音声のみ自動／めくりのみ自動／先生進行 |
| 声 | ペル君／ルルちゃん／博士／おじいちゃん |
| 速度 | 1枚あたりの表示時間 |

### 5.2 カードが持つ項目（種別ごと）

| 種別 | 項目 |
|---|---|
| 絵カード | 絵（画像）／日本語のことば／英語のことば（英語デッキのみ）／読み上げる一文（任意） |
| 文字カード | ひらがな1文字／そのことば／ことばの絵 |
| 対のカード | ことばA／Aの絵／ことばB／Bの絵 |
| 文カード | 本文／よみがな／意味（任意）／作者・出典（任意） |
