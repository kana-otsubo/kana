# video-game-clone

ゲームの画面録画動画を解析して、同様のゲームをこのReactプロジェクトに実装します。

## 使い方
```
/video-game-clone <動画ファイルパス>
```

## 手順

引数として動画ファイルのパスが渡されます: $ARGUMENTS

1. **動画からフレームを抽出する**

まず ffmpeg で動画からキーフレームを抽出します（ffmpeg が使えない場合はユーザーに伝える）:

```bash
mkdir -p /tmp/game-frames
ffmpeg -i "$ARGUMENTS" -vf "fps=2,scale=960:-1" -q:v 2 /tmp/game-frames/frame_%04d.jpg 2>&1 | tail -5
```

2. **フレームを画像として読み込んで解析する**

抽出されたフレームを Read ツールで読み込み、以下を分析します:
- ゲームのジャンル（パズル、アクション、シューティングなど）
- 画面レイアウトとUI要素
- ゲームオブジェクト（プレイヤー、敵、障害物、アイテムなど）
- スコアやライフなどのHUD要素
- 操作方法（ボタンの位置、動きのパターン）

3. **ゲームの仕様をまとめる**

分析結果から以下をまとめる:
- ゲームタイトル（推定）
- コアゲームループ
- 主要なゲームオブジェクトと動作
- 勝利/敗北条件

4. **Reactでゲームを実装する**

`src/games/` ディレクトリ以下にゲームコンポーネントを作成します:
- HTML5 Canvas または CSS/DOM を使ったレンダリング
- requestAnimationFrame によるゲームループ
- キーボード/タッチ操作対応
- スコア表示

5. **App.jsx に組み込む**

作成したゲームを `src/App.jsx` から起動できるようにします。

---

それでは開始します。動画ファイルを解析します。
